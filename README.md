# Celjoe Store

Production-grade food ordering and e-commerce platform built with Next.js 15, TypeScript, Tailwind CSS, Supabase, and PostgreSQL.

## Running locally

Set the required environment variables (example: `.env.local`):

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SITE_NAME` (optional)
- `COMPANY_NAME` (optional)

```bash
pnpm install
pnpm dev
```
